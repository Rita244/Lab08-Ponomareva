## Контрольные вопросы

1. Когда метод останавливается. Проверка: аргумент идёт к этому условию (число уменьшается)
2. Стек вызовов образуется потому, что каждый рекурсивный вызов:
Сохраняет своё состояние
«Замирает» до получения результата от следующего вызова
Потом продолжает работу
3. Идём вниз — потом возвращаемся вверх. Наоборот
4. Разница с циклом в том, что рекурсия тратит больше памяти — каждый вызов сохраняется в стеке. Цикл использует фиксированный объём памяти
5. Ошибка в рекурсии бывает когда:
Нет базового случая
Параметр не меняется при вызове
Параметр удаляется от базового случая (например, n+1 вместо n-1)
6. Все ждут стопкой. Глубокий сработал первым, потом вверх по очереди
